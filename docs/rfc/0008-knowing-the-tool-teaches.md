# How we know the tool teaches

## Question

What does it mean to have understood a company, in a form that can be checked, and how do we find out whether the tool gets a beginner there quickly?

## Why it matters

The project's promise is that using the tool is enough to learn how a company's finances fit together, for 100 companies, in a short time. Nothing so far says how that would be measured. Without it, the first version can be finished and nobody can say whether it worked.

## What we know

- The goal is stated in the README: understand 100 US-listed public companies in a short time, starting with no background.
- The site structure gives each screen one question to answer, in the order a beginner would ask.
- The person building the tool is also its first learner, which makes honest testing possible from day one and biased at the same time.

## Options

### Settled on 11 November 2026: the test for the first version

After 30 minutes with one company, a person can say:

1. How it makes money.
2. Where each dollar of revenue goes.
3. Whether it is growing.
4. What it did with its money.
5. What was happening around it.

The builder is the first person tested. One other person who is new to the field is the second.

## Open points

- How is progress across the 100 kept: a mark per company, notes, or nothing?
- Does the tool need a place for the reader's own notes on a company? Those could not be collected again if lost, unlike everything else in the database.
- Who tests it besides the builder, and when?
- Does the order in which companies are studied matter, starting with simple businesses before complicated ones?
